# Initial local ASR benchmark

Run date: 2026-07-28

## Result

| Model | Aggregate CER | Mean per-clip latency | Warm mean latency |
| --- | ---: | ---: | ---: |
| Qwen3-ASR-0.6B via MLX | 23.485% | 184.1 ms | 183.4 ms |
| Breeze-ASR-25 via PyTorch MPS | 1.515% | 1,017.0 ms | 594.5 ms |

The Breeze mean includes a 3.97 s first inference. Excluding that warm-up,
its mean latency is 594.5 ms. Qwen was already loaded before timing began.

## Method

- Source: eight code-switched clips selected from the public `test` split of
  `ky552/ML2021_ASR_ST`.
- Selection: only utterances whose Mandarin transcription contains ASCII
  English tokens (`decoder`, `encoder`, `autoregressive`).
- Audio: 16 kHz mono WAV, generated by
  `local-stt/prepare_ml2021_benchmark.py`.
- Scoring: the repository's `local-stt/benchmark.py` applies NFKC, lowercases,
  removes whitespace and punctuation, then calculates character edit distance.
- The two JSON reports and downloaded audio live under
  `local-stt/benchmark-data/` and are deliberately untracked.

## Interpretation

Breeze-ASR-25 is materially more accurate on this small, technical
Mandarin-English sample, matching its Taiwan-specific training objective. Qwen
is roughly three times faster after warm-up and remains the lower-memory option.

This is a smoke benchmark, not a deployment-quality evaluation: it uses one
speaker/domain and only eight short clips. Before selecting a default model,
expand the manifest with the user's own Taiwanese conversational dictation,
proper nouns, punctuation expectations, and noisy-microphone recordings.
